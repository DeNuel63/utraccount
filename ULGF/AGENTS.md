# Repository housekeeping

Keep this repository suitable for a Git-based source upload. Retain active source,
tests, configuration, required notebooks, licensing notices and essential usage or
interface documentation. COUNTGD++ and CovTrack_Model are intentional components;
do not treat them as unrelated clutter.

Place generated reports, Word/PDF documents, obsolete upload packages, historical
checklists, one-off review evidence and caches under `_local_archive/`. Maintain
their relative paths and a move manifest when relocating existing work. Never
delete historical results merely to clean the project.

Do not move active inputs or frozen snapshot files without checking dependencies.
Keep required local weights/data ignored by Git at their working paths until a
verified relocation is available. Do not mutate the experiment baseline snapshot.

Keep the current detailed progress checklist in `_local_archive/PROJECT_CHECKLIST.md`.
Update it from execution evidence, distinguishing code implemented, tests passed,
runtime verified and results accepted. Never infer training or temporal quality
from layout tests or a compositing demonstration.

Preserve upstream attribution and license notices. A root license does not establish
redistribution rights for third-party code, datasets, checkpoints or supplied images.
Do not initialize, commit, push or publish merely to answer a status request.
